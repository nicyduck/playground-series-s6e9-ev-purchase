# Final submission checklist

- [ ] 提出候補はOOF ROC AUCとfold間のばらつきで選んだ
- [ ] OOF予測が全train行にちょうど1回ずつ存在する
- [ ] train全体で再学習、またはfold予測平均でtestを予測した
- [ ] submissionの行数・`id`・列順がsample_submissionと一致する
- [ ] `Will_Buy_EV` に欠損・無限値がなく、値が0〜1に収まる
- [ ] 実験ID、seed、特徴量、パラメータ、OOFスコアを台帳に記録した
- [ ] 提出ファイルの説明文と作成元実験を提出台帳に記録した
- [ ] 外部データ・公開予測を使った場合、出所と再現方法を記録した
- [ ] Public LBだけを根拠に最終候補を選んでいない
- [ ] 締切前に最終提出として選択されたことをKaggle画面で確認した
